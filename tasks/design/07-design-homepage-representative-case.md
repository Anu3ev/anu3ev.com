# DES-07: Design the Homepage Representative Case

**Status:** Planned  
**Depends on:** DES-06

## Objective

Validate the visual language, content hierarchy, token system, and core components on one complete mobile-first user journey.

## Deliverables

- Dark English home page at 390 px using real content.
- Russian content variant without manual type-size reductions.
- Hero, evidence summary, featured work, expertise, experience, writing, portrait, contact CTA, and footer sections.
- Primary `View selected work` and secondary contact actions.
- Documented changes required in foundations or components after screen validation.

## Acceptance criteria

- Role, experience level, and value are understandable within the first viewport.
- Projects and evidence dominate over decoration.
- English and Russian layouts remain coherent with realistic content lengths.
- The page has a clear route to work samples and contact.
- Any repeated screen-level patch is resolved at the token or component contract.
