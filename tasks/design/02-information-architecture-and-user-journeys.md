# DES-02: Define Information Architecture and User Journeys

**Status:** Completed
**Depends on:** DES-01

**Result:** [Information architecture and user journeys](../../docs/design/information-architecture.md)

## Objective

Define a clear bilingual site structure and the paths that lead each audience to relevant proof and contact actions.

## Deliverables

- Approved sitemap for Home, Work, Case Study, Writing, Article, About, Contact, Privacy, and 404.
- Recruiter, engineering-leader, client, and article-reader journeys.
- Section order and content priority for the home page.
- Case-study narrative structure: context, constraints, role, decisions, outcome, and evidence.
- English/Russian route correspondence table.
- Primary and secondary calls to action for every page template.

## Acceptance criteria

- A visitor can reach a relevant case study and contact action without ambiguous navigation.
- Home-page sections support the hiring goal before secondary client or blog goals.
- English and Russian routes have one-to-one equivalents.
- No page exists only because it is common on portfolio websites.
- Navigation labels describe user-facing destinations rather than implementation details.
