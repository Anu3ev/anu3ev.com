# DES-03: Create the Figma File and Lock the Library Scope

**Status:** Planned  
**Depends on:** DES-01, DES-02

## Objective

Create a single maintainable Figma file and agree on the exact first-version design-system scope before building components.

## Deliverables

- Figma design file named `anu3ev.com — Website & Design System`.
- Inspection of available libraries, fonts, variables, styles, and reusable assets.
- Page structure for Cover, Getting Started, Foundations, Components, Patterns, Screens, Utilities, and Archive.
- Locked list of first-version tokens, components, patterns, and screen templates.
- Gap analysis covering what exists in content, code, Figma, and external libraries.

## Acceptance criteria

- No component creation begins before the scope and gap analysis are reviewed.
- Reused assets have compatible properties, token bindings, naming, and ownership.
- Every planned component is required by an approved screen or interaction.
- Figma page and object names follow one deterministic convention.
- The file can be resumed safely without relying on conversation history.
