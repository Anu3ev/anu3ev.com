У каждой задачи — отдельная папка в `docs/tasks/`, описание результата и `summary.md`. Статус означает реально выполненную работу. Необходимые операционные инструкции появятся в `docs/operations/`.

Исторический factual inventory сохранён в `reference/` только как источник фактов. Его старые решения, статусы approval и ссылки на удалённый прототип заменены этой архитектурой и текущим заданием.
