Избранные проекты · 2021–2026

Продуктовая frontend-разработка для продавцов, редакторов и сложных браузерных сценариев

Здесь показан мой frontend-вклад внутри кросс-функциональных продуктовых команд. Публичный репозиторий редактора служит отдельным подтверждением и не является источником данных о production-использовании в inSales.

01 · Редактор изображений товаров

Переиспользуемое ядро редактора, которым пользуются тысячи клиентов inSales

Я разрабатывал библиотеку на TypeScript и FabricJS и интегрировал её в продуктовые сценарии. Она отвечает за состояние canvas, history, crop, слои, rich text, шаблоны, экспорт, AI-операции с изображениями и API для основного продукта.

  • Общее ядро для административной панели и редактора темы
  • Jest и Playwright для поведения со сложным взаимодействием
  • Публичный репозиторий GitHub, npm-пакет и live demo

02 · Брошенные корзины

Аналитика и коммуникация в одном сценарии продавца

Продуктом пользуются более 1 000 клиентов. Данных о возвращённой выручке или конверсии нет, поэтому я не привожу такие показатели.

  1. 01Аналитика, графики и выбор периода
  2. 02Таблицы, поиск, фильтры и пагинация
  3. 03Состав корзины, товары, итог и статус
  4. 04История коммуникации и отправка сообщений
  5. 05Feature flag, передача в QA и проверка в production

03 · E-commerce-сценарии

Контент, checkout, формы и инструменты витрины

В нескольких небольших продуктовых областях задача была похожей: превратить бизнес-правила и ограничения старой платформы в предсказуемое поведение браузера.

  • AI-описания товаровГенерация, проверка, редактирование, состояния ошибок и согласование backend API внутри TinyMCE.
  • Корзина и checkoutОпции товаров, дополнительные услуги, заказ в один клик и выбор склада отгрузки.
  • Captcha-провайдерыreCAPTCHA v2 и v3, Yandex SmartCaptcha, повторные попытки, мобильная клавиатура, overlay и поведение Safari.
  • Редактирование шаблонов в MonacoРедактор кода и preview после того, как WYSIWYG-обработка повреждала HTML и Liquid-шаблоны.

04 · Модернизация и UI-основа

Миграция на Vue 3 и переиспользуемые компоненты Vuetify

Я участвовал в production-миграции с Vue 2 на Vue 3. Переписывал инфографические компоненты на script setup, выносил состояние редактора в composables и сохранял поведение в разных продуктовых контекстах.

Отдельно я расширял внутренний UI kit на Vuetify переиспользуемыми компонентами и паттернами для административной панели. Это была работа над компонентами, а не владение дизайн-системой всей компании.

  • Vue 2 и Vue 3
  • Composition API
  • script setup
  • Vuetify
