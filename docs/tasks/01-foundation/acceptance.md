# Критерии приёмки

- Все ссылки основной навигации, карточек проектов и статей открывают реальные страницы; прямой reload работает.
- Макет сверяется с Home/Blog MagicPath после доступа; остальные страницы используют те же токены. Проверяются desktop, 768, 375 и 320 px.
- Кнопки и controls имеют видимую подпись или доступное имя и `title`. Native ссылки, кнопки, labels; skip link, focus ring, semantic landmarks, один h1.
- Меню открывается клавиатурой, закрывается Escape и после навигации; focus остаётся предсказуемым. Переключатель языка сохраняет эквивалент страницы. Тема сохраняется, не вызывает hydration mismatch.
- Без JavaScript основные тексты и навигация доступны в HTML.
- Статьи: 0, 1, 10, 11, 20, 21 записей; границы страниц, отсутствие дубликатов, draft/future exclusion, некорректный URL → 404.
- CMS доступна по `/admin/`, конфигурация соответствует контенту и репозиторию. В build нет секретов. Вход с личным токеном проверяется только если пользователь сам предоставил сессию; наличие login screen не выдаётся за проверенную запись в GitHub.
- Проверяются title, description, canonical, OG image dimensions, hreflang и валидный JSON-LD. В sitemap/RSS нет draft, admin, 404 и дубликатов.
- Unit покрывают поведение пагинации и небезопасные входы. E2E — navigation, статья, кейс, mobile menu, locale/theme, 404. Axe — основные шаблоны в обеих темах; не выдаём автоматическую проверку за полную сертификацию WCAG.
- CI проходит на GitHub; semver release с артефактом существует; production открывается по публичному HTTPS URL без авторизации.
- Нет секретов, внутренних заметок целиком, приватного кода работодателя и придуманных метрик.
- В summary указаны реальные pass/fail/skip и ограничения, а также коммит/PR и ссылка на опубликованный результат.
