# 36 — Relocation on Home

From the external portfolio review: relocation appeared only on Contacts, so a recruiter scanning the home page would not see it.

The home location line now reads "Remote · B2B / EOR · Relocation" / «Удалённо · B2B / EOR · Релокация». It uses the same word as the Contacts arrangement tags, and the same offer as the CV ("Open to employer-sponsored relocation").

**Test.** The settings-driven home test now checks, in both languages, that the location line contains the relocation arrangement from the Contacts settings. If the two pages drift apart, it fails.
