# Review and corrections

Reviewed requirements, source evidence and the connections between static routes, SEO, the content database, images and browser tests. This was author self-review and automated checking, not independent review.

1. **Publication/routes.** Nitro and sitemap share `createPublicPaths`. A real temporary Nuxt build has 12 synthetic articles per language: ten on page one, two on page two, direct reload and Russian equivalents, with page three returning 404. Only declared app inputs are copied, excluding Git, environment files and browser profiles; checkout/cache are isolated and fixture content is never deployed.
2. **SEO.** Canonical trailing slashes, equivalent hreflang and JSON-LD identify the same document. Browser tests exposed a mainEntityOfPage mismatch after a static-server redirect; the fix also covers cases. Article modification dates are not invented. Launch-day articles sort deterministically by slug when dates match.
3. **JSON-LD/XML.** Escape `<` in inline JSON and text/attributes in XML. A unit test covers a closing script tag in an editable heading. Both RSS feeds contain only public entries and parse as XML. Manifest, favicon and apple-touch-icon are generated.
4. **Accessibility.** The first run found a monogram label-in-name problem, low-contrast light-theme labels and unclear pagination names. Corrected all related places; decorative fills are separate from text colors. The logo's accessible name includes visible `a.`; pagination links use Page N. Unknown Russian routes render a localized 404.
5. **Mobile contrast.** Lighthouse found the CTA over the graphic cover. It now has an opaque theme background; mobile axe covers both themes.
6. **Performance.** Initial mobile Lighthouse was 86/96/100/100 with LCP 3.4 s. Replaced a blocking theme request with a small prepaint inline bootstrap. Local preloaded Latin/Cyrillic font URLs are normalized so SSR-relative and client-absolute forms do not duplicate requests during hydration; a regression covers this. Route prefetch happens on interaction rather than competing with initial paint.
7. **Images.** Build-time Sharp creates 640/960/1200 WebP card sources; originals remain available on cases. Generated directories are cleaned by their owner. Changing a cover during a running dev session requires `pnpm assets:prepare` or restart.
8. **Compression.** Nitro emits Brotli/Gzip and preview actually returns `Content-Encoding: br`. No runtime image service is required.
9. **Readability.** Vue markup separates meaningful blocks while preserving inline spaces. `app/queries/posts.ts` owns published post projection/order for Home and Blog. Fixture article creation is separate from checkout/cache isolation. Composable review confirmed router-owned locale, no cross-request singleton, hidden root event chains or uncleaned timers.
10. **Facts.** The CV updated on 16 October 2026 confirms the frontend role ended in September 2026. The old inventory is not used.

Final Fallow at this stage had no dead code, unused imports/exports, cycles, boundaries, duplication or function-complexity findings. Its warn verdict included CSS heuristics and four conditional test skips for a completely empty public collection; the actual full run skipped **zero**. Vue Router creates `router-link-exact-active`; Tailwind owns `--font-sans`; reduced-motion `!important` intentionally overrides motion. Scoped selectors and relative inline-code sizing were checked against the cascade rather than changed just for a score.

Static admin `noindex,nofollow` and Sveltia's added noindex tag are compatible: Google combines directives. Tests do not require one vendor tag. [Google Search Central](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag).

Limits: Chromium only; axe/Lighthouse are not full manual WCAG certification. Core Web Vitals here are laboratory results; field INP/CrUX require traffic. The first personal-token sign-in/write remains the owner's action; no token was extracted.
