# Decision Records

This directory contains durable decisions that affect more than one task or define a project-wide contract.

## Status values

- Proposed: under discussion and not yet binding.
- Accepted: current project contract.
- Superseded: replaced by a newer numbered decision.

## Naming

Use NNNN-clear-kebab-case-name.md. Keep one decision per file. Later changes receive a new number and link back to the superseded record.

## Required structure

Every decision record contains:

- status and date;
- context;
- decision;
- consequences;
- links to related documents or tasks.
